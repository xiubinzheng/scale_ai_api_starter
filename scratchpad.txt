Task 1 build an evaluation job API 

We're building a service that allows customers to submit AI-generated responses for quality evaluation.

For example, a customer might submit a question, 
an AI-generated answer, and an expected reference answer.

Our service will eventually evaluate the quality of the generated answer.


For now, we just need to accept and store evaluation jobs.

Requirements
Implement two HTTP endpoints.

1. POST /evaluations

Accept a JSON request:
{
  "question": "What is the capital of France?",
  "generated_answer": "Paris",
  "reference_answer": "Paris"
}

The endpoint should:
- Validate the request.
- Generate a unique job_id.
- Store the evaluation job with an initial status of pending.
- Return HTTP 201 Created.


{
  "job_id": "abc-123",
  "status": "pending"
}

2. GET /evaluations/{job_id}

Retrieve a previously submitted evaluation job.

Example response:
{
  "job_id": "abc-123",
  "question": "What is the capital of France?",
  "generated_answer": "Paris",
  "reference_answer": "Paris",
  "status": "pending"
}


Acceptance criteria
- Each submission receives a unique job ID.
- All three text fields are required and must be nonempty strings.
- Jobs can be retrieved by their IDs.
- Unknown job IDs return HTTP 404.
- Invalid input returns an appropriate HTTP error.
- Write pytest tests covering the main functionality.
Scope: For this first task, in-memory storage is sufficient. You do not need a database, background workers, or LLM integration yet.
